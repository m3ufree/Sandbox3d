# Sandbox 3D — песочница с машинкой и NPC

3D-песочница на Python + [Ursina](https://www.ursinaengine.org/): ходьба от первого лица, машина с видом от третьего лица, NPC, которые гуляют по городу, дома, деревья и ящики.

## Запуск на компьютере

```bash
pip install ursina
python game.py
```

## Запуск на телефоне (Android)

1. Установите [Pydroid 3](https://play.google.com/store/apps/details?id=ru.iiec.pydroid3).
2. В Pydroid 3: меню → Pip → установите `ursina`.
3. Откройте `game.py` и запустите.

Сенсорное управление включено всегда: кнопки внизу экрана.

## Управление

| Действие | Клавиатура | Телефон |
|---|---|---|
| Ходьба | WASD / стрелки | ▲ ▼ ◀ ▶ |
| Прыжок | Space | — |
| Сесть / выйти из машины | E | кнопка E |
| Газ / тормоз-назад | W / S | GAS / BRK |
| Поворот в машине | A / D | ◀ ▶ |
| Осмотр | мышь | свайп по экрану |

## Что внутри

- `player` — контроллер от первого лица (Ursina FirstPersonController)
- `Car` — машинка: разгон, задний ход, поворот, камера-слежка, столкновения (raycast)
- `NPC` — 10 прохожих, случайно бродят по карте
- Процедурная генерация: 14 домов, 20 деревьев, 6 ящиков на поле 120×120
